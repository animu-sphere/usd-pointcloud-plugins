# OpenUSD Point Cloud Plugins v0.11.0

Released 2026-08-27.

## Scope

This release makes the four existing FileFormat plugins an independently
composable aggregate product. It installs component-owned probes for LAS, LAZ,
PLY, COPC, and the external HTTP/COPC Tier 2 scenarios. No point decoding,
georeferencing, cache-key, or public C++ contract changes from v0.10.0.

## Product contents

- Exact release members: `pointcloud-copc`, `pointcloud-las`,
  `pointcloud-laz`, and `pointcloud-ply`.
- Acceptance data under `share/usd-pointcloud-plugins/probes`.
- Per-member archives, manifests, checksums, SPDX SBOMs, and provenance are
  retained alongside the aggregate product payload.

## Compatibility

- CY2026 / OpenUSD 26.08, Python 3.13.
- OpenStrata 0.22.8 or newer is required for direct runtime composition of the
  aggregate product archive.
- Existing local format behavior and v0.10.0 resolver identity/cache decisions
  remain compatible.

## Verification

Release preparation runs workspace CTest, all four plugin pyramids, packaged
local fixtures, and HTTP/COPC Tier 2. Strong ETag revisions produce distinct
validation identities, weak ETags remain unstable, remote points match the
local digest, and at least one byte-range request is retained in evidence.
Repeated packaging must reproduce the same SHA-256 inventory.

## Dependencies and licensing

Apache-2.0 project code is unchanged. LAZ and COPC retain laz-perf 2.0.0 under
LGPL-2.1 with the existing corresponding-source and notice material.

## Known limitations

- Tier 2 uses synthetic and recorded fixtures; it does not establish broad
  public-server interoperability or geographic accuracy.
- Products are target-specific and must match the composed OpenUSD ABI.
- Remote transport remains owned by an external resolver component.
