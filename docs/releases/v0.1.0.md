# OpenUSD Geospatial Geometry Plugins v0.1.0

Release date: 2026-08-01

## Summary

The first public release of OpenUSD Geospatial Geometry Plugins. This release establishes the
shared geospatial and point-cloud contracts and imports LAS and LAZ point
clouds into OpenUSD through FileFormat Plugins.

## Included

- LAS 1.2-1.4 headers, VLR/EVLR metadata, WKT CRS, and point records.
- LAZ chunk decoding through the vendored `laz-perf 2.0.0` adapter.
- `UsdGeomPoints` authoring with positions, CRS metadata, local origin,
  bounds, and point-count metadata.
- Stable machine-readable diagnostics for invalid or unsupported input.
- Core CMake build and test targets independent of an OpenUSD runtime.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for the USD authoring and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Known limitations

Tile/LOD streaming, a USDC cache, and rendering are outside this release.
Rendering is supplied by the consuming OpenUSD application.
