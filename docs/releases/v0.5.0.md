# OpenUSD Point Cloud Plugins v0.5.0

Release date: 2026-08-12

## Summary

This feature release adds resolver-backed COPC reads through the active OpenUSD
`ArResolver`. It also introduces the first transport-independent source
identity contract for generated caches and validates the resolver integration
path across the supported hosted CI platforms.

## Breaking changes

None. Existing LAS, LAZ, COPC, and PLY format ids, file-format arguments,
authored stage shape, and local cache behavior remain compatible with v0.4.0.
Resolver-backed COPC access uses the existing `copc` format id and requires the
active resolver to provide the asset.

## Included

- COPC random access through an adapter from OpenUSD `ArAsset` to the shared
  project-owned `RandomAccessSource` contract.
- COPC FileFormat reads through the active `ArResolver` for local and
  resolver-provided assets, including metadata-only, direct, and hierarchy-backed
  tiled reads where the resolver supplies the required ranges.
- Typed diagnostics for resolver-open failures, unavailable ranges, short reads,
  and invalid remote tiled payload-directory configuration.
- The `usdgeo::cache::SourceIdentity` contract with stable identifiers,
  validation tokens, and optional local file metadata.
- Shared local filesystem identity construction for authoring and the
  `usd-pointcloud-convert` tool.
- The `httpresolver` OpenUSD asset-resolver test double and Windows, Linux, and
  macOS CI coverage for the resolver integration boundary.
- Corrected resolver bundle packaging as an OpenUSD `usd-asset-resolver` plugin.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for USD authoring, resolver, and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Compatibility

The LAS, LAZ, COPC, and PLY plugin bundles target OpenUSD `>=26.08,<27.0` and
the `cy2026` / `usd` OpenStrata platform and profile. The `httpresolver` bundle
is an integration-test double and is not a production network transport.

COPC resolver-backed reads depend on the active OpenUSD resolver for transport,
authentication, retries, and any network caching. Generated cache reuse remains
disabled when the source does not provide a stable local filesystem identity.

## Known limitations

- The repository does not include a generic HTTP client, authentication flow,
  retry subsystem, network cache, or resolver-backed generated-cache identity.
- Remote COPC tiled reads require an absolute local `payloadDirectory`.
- COPC writing, adaptive tiling, and new public USD schemas remain deferred.
- Writing LAS, LAZ, COPC, or PLY is out of scope; the existing plugins export
  `usda` where supported.

publishes SHA-256 checksums. The v0.5.0 preparation was validated with the

path and the `httpresolver` plugin checks.
