# OpenUSD Point Cloud Plugins v0.7.0

Release date: 2026-08-13

## Summary

This feature release adds deterministic point-budget adaptive tiling while
preserving the existing fixed-grid path. It also adds tile planning statistics,
typed planning diagnostics, and reproducible cross-format streaming benchmarks
for LAS, LAZ, COPC, and PLY.

## Breaking changes

None. Existing LAS, LAZ, COPC, and PLY format ids, file-format arguments,
authored stage shape, and fixed-grid tiling behavior remain compatible with
v0.6.0.

## Included

- Deterministic point-budget planning over source X/Y positions with minimum and
  maximum points per tile and a maximum depth.
- `PointBudgetPlan` statistics for point count, tile count, minimum, maximum,
  and average leaf density, split count, and reached depth.
- Typed diagnostics when a source distribution cannot satisfy the requested
  point budget.
- Fixed-grid compatibility coverage for `tileSize` and `tileMemoryLimit`.
- Cross-format streaming benchmark coverage for LAS, LAZ, COPC, and PLY using
  shared chunk, tile, and memory settings.
- A generated COPC benchmark fixture and a machine-readable
  `cross-format.tsv` report containing comparable point, tile, memory, payload,
  and elapsed-time metrics.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for USD authoring, resolver, and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Compatibility

The LAS, LAZ, COPC, and PLY plugin bundles target OpenUSD `>=26.08,<27.0` and
the `cy2026` / `usd` OpenStrata platform and profile. Adaptive point-budget
planning is additive; callers using the existing fixed-grid arguments retain
their established behavior. The generated-USDC cache and resolver or transport
byte-range caches remain separate.

## Known limitations

- Broader real-world cross-format baselines require representative datasets
  that are not shipped in the repository.
- Target payload-byte and spatial-size fallback policies are not part of this
  release.
- COPC writing and new public USD schemas remain deferred.
