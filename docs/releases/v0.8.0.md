# OpenUSD Point Cloud Plugins v0.8.0

Release date: 2026-08-14

## Summary

This feature release closes the real-world measurement and I/O observability
milestone. It records reproducible fixed-grid and adaptive baselines for LAS,
LAZ, COPC, and PLY, and hardens the LAZ and Windows spool paths needed to run
fine-grained COPC measurements.

## Breaking changes

None. Existing LAS, LAZ, COPC, and PLY format ids, file-format arguments,
authored stage shape, and fixed-grid tiling behavior remain compatible with
v0.7.0.

## Included

- Fixed-grid versus adaptive real-world matrix coverage for Shizuoka LAS and
  LAZ, Autzen COPC, and Stanford Bunny PLY inputs.
- TSV and JSON reports containing corpus identity, source SHA-256, normalized
  settings, tile distributions, tree depth, peak RSS, source bytes, spool
  bytes written and read, payload bytes, elapsed time, and I/O amplification.
- LAS 1.4 point-format-7 LAZ regression coverage with RGB and optional
  compressed substreams.
- LAZ reader support for the compressor version emitted by LAS 1.4 point
  formats 6-8, plus safe handling of absent optional point-format-7 streams.
- Windows spool descriptor scaling beyond the CRT default of 512 simultaneously
  open files, allowing the documented fine-grid Autzen run to complete.
- External payload-directory support for FileFormat tiled authoring when a
  tile manifest sidecar is not requested.

## Real-world verification

The final Windows/OpenUSD 26.08 matrix completed all eight fixed-grid and
adaptive rows:

| Dataset | Points | Fixed tiles | Adaptive tiles |
| --- | ---: | ---: | ---: |
| Shizuoka LAS | 14,574,030 | 12 | 28 |
| Shizuoka LAZ | 14,574,030 | 12 | 28 |
| Autzen COPC | 10,653,336 | 977 | 16 |
| Stanford Bunny PLY | 35,947 | 185 | 16 |

The reproducibility command and corpus provenance are documented in
[streaming-and-tiling.md](../roadmap/streaming-and-tiling.md) and
[real-world-tiling.example.json](../../tools/real-world-tiling.example.json).
The datasets and generated reports remain build-local and are not included in
plugin products.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for USD authoring, resolver, and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Known limitations

- Host responsiveness during interactive output use remains unmeasured.
- Target payload-byte and spatial-size fallback policies are not part of this
  release.
- COPC writing and new public USD schemas remain deferred.

## Verification

The local Windows `cy2026` / `usd` Release build passed all 21 CTest tests when
run serially. The LAZ and COPC unit tests, cross-format benchmark tests, and
all four plugin integration tests passed. The real-world matrix completed
without failures for LAS, LAZ, COPC, and PLY in both tiling strategies.

The release workflow validates the tag against `VERSION`, checks all release
metadata declarations, validates the OpenStrata CI matrix, runs the declared
cross-platform source and plugin lanes, packages the plugin products, and
publishes SHA-256 checksums.
