# OpenUSD Point Cloud Plugins v0.2.2

Release date: 2026-08-06

## Summary

This patch release corrects the version metadata used by the OpenStrata
workspace and the LAS and LAZ plugin packages. It contains no runtime,
file-format, or public API changes from v0.2.1.

## Fixed

- Platform plugin archives and the combined product archive now use version
  `0.2.2` consistently.
- Release preparation validates the workspace, plugin manifest, and CMake
  version declarations before a tag build.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for the USD authoring and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Compatibility

The LAS and LAZ format ids, file extensions, file-format arguments, authored
stage, and plugin discovery paths are unchanged from v0.2.1.

## Known limitations

Unchanged from v0.2.1; see [the v0.2.1 release record](v0.2.1.md).

The release workflow validates the tag against `VERSION`, checks all release
metadata declarations, runs the declared OpenStrata CI cells on Windows,
Linux, and macOS, packages both plugins, and publishes SHA-256 checksums.
