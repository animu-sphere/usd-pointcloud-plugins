# OpenUSD Point Cloud Plugins v0.3.0

Release date: 2026-08-11

## Summary

This feature release adds local, read-only COPC support through the shared
point-cloud, streaming, tiling, diagnostics, and `usdLod` contracts. It adds
the `pointcloud-copc` OpenUSD FileFormat Plugin and completes deterministic
USDC cache reuse for the conversion tool and direct FileFormat reads.

## Breaking changes

None. The existing LAS and LAZ format ids, file extensions, diagnostic code
prefixes, file-format argument syntax, and authored stage remain compatible
with v0.2.2. COPC support adds the `copc` format id and `.copc` extension.

## Included

- COPC Info VLR and local hierarchy page validation.
- Selective COPC point-data range reads through the shared LAZ chunk decoder.
- Native COPC hierarchy point streaming and mapping to the shared tile and LOD
  model.
- Metadata-only, non-tiled, and hierarchy-backed tiled COPC FileFormat reads.
- Regression coverage for LAS, LAZ, and COPC point-stream and authored-LOD
  equivalence.
- Deterministic USDC cache generation through `--cache-root` and direct cache
  lookup through `USDGEO_CACHE_ROOT`.
- Release products containing the LAS, LAZ, and COPC plugin bundles, manifests,
  SBOMs, compatibility documents, installation instructions, and checksums.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for the USD authoring and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Compatibility

The three plugin bundles target OpenUSD `>=26.08,<27.0` and the `cy2026` / `usd`
OpenStrata platform and profile. COPC reads are local-only and require the
source hierarchy and point-data ranges to be available from a local file.

## Known limitations

- COPC writing, HTTP range sources, network caching, and new public USD schemas
  are deferred.
- Tiled reads use fixed-grid planning and bounded spool-backed generation;
  broader real-world dataset coverage remains open.
- Waveform sample data is retained as packet metadata and external `.wdp`
  references but is not fetched or interpreted.
- Writing LAS, LAZ, or COPC is out of scope; all three plugins export as `usda`.
