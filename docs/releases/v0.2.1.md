# OpenUSD Point Cloud Plugins v0.2.1

Release date: 2026-08-06

## Summary

This patch release stabilizes the LAS and LAZ implementation after v0.2.0. It
adds source-coordinate bounds and classification filters, EPSG inference with
conflicting-CRS diagnostics, and the operational conversion path for
payload-backed tiled generation. It also completes interruption cleanup,
deterministic manifest publication, and real-data working-set measurement for
the documented LAS and LAZ paths.

## Breaking changes

None. The LAS and LAZ format ids, file extensions, diagnostic code prefixes,
file-format argument syntax, and authored stage remain unchanged.

## Included

- Bounds and classification filters for LAS and LAZ, normalized into canonical
  file-format arguments and evaluated before stage-local transforms.
- EPSG inference from explicit WKT and GeoTIFF horizontal CRS keys, with typed
  rejection of conflicting CRS definitions.
- The `usd-pointcloud-convert` tool as the production path for long-running
  tiled, payload-backed generation.
- Deterministic `<root>.manifest` output containing normalized generation
  arguments and relative payload paths.
- Recovery of interrupted conversion transactions and cleanup validation for
  cancellation, failure, and incomplete payload workspaces.
- Real-dataset processing-time, RSS, spool, payload, and payload working-set
  measurements for the documented LAS and LAZ paths.
- Synchronized capability, implementation-status, build, and release
  documentation.

## Requirements

- CMake 3.23 or newer.
- A C++17 compiler.
- OpenUSD 26.08 for the USD authoring and plugin targets.
- OpenStrata 0.21.0 for the pinned workspace build.

## Known limitations

- Rendering is supplied by the consuming OpenUSD application.
- Tiling uses a fixed-grid `tileSize`; adaptive depth and point-budget tile
  planning are not exposed through LAS/LAZ file-format arguments.
- A deterministic USDC cache is not implemented, and broader real-world
  dataset coverage remains open.
- Waveform sample data is retained as packet metadata and external `.wdp`
  references but is not fetched or interpreted.
- Writing LAS or LAZ is out of scope; the plugins export `usda`.
