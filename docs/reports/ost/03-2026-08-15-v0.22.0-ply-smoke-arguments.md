# OST v0.22.0 follow-up - structured PLY smoke arguments

- Date: 2026-08-15
- Release: `ost v0.22.0`
- Repository target: `pointcloud-ply`
- Source report: [01-2026-08-11-v0.22.0-ply-fileformat-ci.md](01-2026-08-11-v0.22.0-ply-fileformat-ci.md)

## Result

The OpenStrata P2 ask from report 01 is resolved in `ost v0.22.0`. A smoke
fixture can now declare a relative path and FileFormat arguments directly in
`openstrata.plugin.yaml`.

The PLY manifest now uses:

```yaml
tests:
  smoke:
    - path: tests/fixtures/conformance.ply
      file_format_arguments:
        epsg: "4978"
```

The existing `conformance.usda` wrapper is no longer selected by the smoke
manifest. It remains checked in as historical coverage for the wrapper-based
workaround described in report 01.

## Local verification

The installed CLI reported `ost 0.22.0`. The direct PLY fixture passed the
verification pyramid through L4:

```text
$ ost plugin test plugins/pointcloud-ply --target cy2026 --profile usd --up-to 4 --json
"usdcat read 'conformance.ply' and emitted USDA"
"Usd.Stage.Open() opened the fixture"
"passed": true
```

The complete result was 11 passed and 4 skipped diagnostics. The skipped
checks were the expected ABI/runtime-library checks for this bundle.

The CI contract also remains valid under `ost v0.22.0`:

```text
$ ost ci validate --matrix openstrata.ci.yaml
Matrix openstrata.ci.yaml: 27 cell(s), structure OK
```

This closes the report 01 follow-up. The PLY plugin still requires an explicit
`epsg` argument when opened directly because PLY does not carry an embedded CRS.
